# JI Creative Ventures LLC

Official website for **JI Creative Ventures LLC**, an independent software studio
designing and building native iOS applications for iPhone and iPad.

🌐 **Live site:** https://jkinchalik.github.io/jicreativeventuressite/

## About this repository

A static single-page website served via **GitHub Pages**. It is deployed
automatically by the workflow in `.github/workflows/pages.yml` on every push to
`main`.

## Local preview

Open `index.html` directly in a browser, or run a simple local server:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```
